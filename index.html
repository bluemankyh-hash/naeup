나의 업무

가입 전이것만 준비해 주세요

  1. 구글 계정 하나지메일 주소면 돼요. 이 계정의 구글 드라이브에 내 자료가 저장돼요.회사용·개인용 중 앞으로 계속 쓸 계정으로 정해 주세요.
  2. "확인하지 않은 앱" 창이 나오면[고급] → [나의 업무(으)로 이동(안전하지 않음)] → [허용]을 눌러 주세요.구글 심사를 받지 않은 개인 앱이라 나오는 안내예요. 권한은 내 드라이브·시트·메일 보내기에만 쓰여요.
  3. 가입 신청서 쓰기아래에 이름·회사·연락처를 적고 [가입 신청]을 눌러 주세요.
  4. 승인 기다리기관리자가 확인하고 승인하면 메일이 와요. 보통 하루 안에 처리돼요.

승인 후처음 한 번만 해 주세요

  1. 승인 메일의 [나의 업무 열기]가입할 때 쓴 구글 계정으로 열어 주세요.
  2. [내 자료 공간 만들기] 누르기내 구글 드라이브에 「나의 업무」 폴더와 시트가 만들어져요 (1분쯤).내 자료는 나만 보고, 다른 사람(관리자 포함)은 볼 수 없어요.
  3. 홈 화면에 추가아이폰: 사파리 아래 [공유] → [홈 화면에 추가]. 안드로이드: 크롬 ⋮ → [홈 화면에 추가]. 한 번 로그인하면 계속 열려요.
  4. 내 정보 넣기[문서 작성] → [⚙️ 정보/직인]에서 회사 이름·사업자번호·직인을 넣어 주세요.
  5. 단가표 넣기시트의 「스페이스프로」·「코팅코리아」 탭에 품목·단가를 넣어 주세요 (쓰는 경우만).
  6. 서류는 추출함에드라이브 「나의 업무/추출함」에 주문서·명함·사업자등록증을 넣으면 10분마다 자동으로 읽어요.
